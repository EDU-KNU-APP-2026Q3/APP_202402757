- W08_HW.unity는 Assets/W06_HW/W06_HW.unity를 복사한 게임 씬입니다.
- W06의 캐릭터, 애니메이션, 적 프리팹, 공격 로직은 그대로 참조합니다.
- 시작 화면과 게임오버 화면의 '기록 보기'로 기록 패널을 엽니다.
- '돌아가기'는 기획서에 맞게 시작 화면으로 이동하고, '다시 하기'는 새 라운드를 시작합니다.

기록 표시
- 기존 ScoreManager의 HighScore와 TopScores를 읽습니다.
- TopScores가 비었으면 '아직 기록이 없어요'와 순위별 '-'를 표시합니다.
- 0점으로 완료한 라운드는 정상 기록이며, 기록 없음과 구분합니다.
- 점수 저장은 기존 ScoreManager의 PlayerPrefs 기능을 사용합니다.

화면 대응
- Canvas Scaler: Scale With Screen Size / 1080×1920 / Expand
- Safe Area 적용
- 세로: 최고 기록 위, Top 3 아래
- 가로: 기획서처럼 같은 세로 패널을 중앙에 두고 좌우를 배경으로 채움
- 흰색 패널, 옅은 파란색 최고 기록 영역, 간결한 순위 목록, 분홍색 돌아가기 버튼
- 제목·돌아가기 버튼은 각각 패널의 위·아래에 배치하며 텍스트는 영역 내 자동 크기 조절

Prefabs: W08 전용 Managers 및 ScoreBoard
